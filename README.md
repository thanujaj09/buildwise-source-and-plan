# Buildwise Source And Plan

Design a modern construction-material procurement app called BuildWise AI. Create five connected screens: home page, material catalogue, supplier comparison, quantity estimator, and order enquiry form. Use a navy blue and teal colour scheme, clear buttons, simple icons, and readable text. Use fictional suppliers and clearly labelled demo prices. Make the screens look consistent and suitable for a datathon prototype.
